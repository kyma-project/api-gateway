## New Features

- The API Gateway module now provides a dedicated Kyma dashboard UI for managing RateLimit custom resources (CRs). You can create and edit RateLimit CRs using a guided form with inline validation hints, view all your RateLimit CRs in a list, and check each CR's effective configuration and related Pods. See [PR #2885](https://github.com/kyma-project/api-gateway/pull/2885).
