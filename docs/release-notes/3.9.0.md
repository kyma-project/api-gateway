## New Features

- The ExternalGateway controller now reports more meaningful condition reasons and detects duplicate domains across ExternalGateway resources. A new [ExternalGateway troubleshooting guide](https://kyma-project.io/external-content/api-gateway/docs/user/troubleshooting-guides/03-90-external-gateway-troubleshooting.html) is available in the documentation. See [PR #2744](https://github.com/kyma-project/api-gateway/pull/2744).

## Bug Fixes

- The ExternalGateway controller now creates the Istio Gateway resource at the same point as the EnvoyFilters, preventing a state where the Gateway is `Ready` but no EnvoyFilters are in place to guard workloads. See [PR #2735](https://github.com/kyma-project/api-gateway/pull/2735).
