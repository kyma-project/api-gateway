## New Features

- Reconciliation of APIRule `v1beta1` is disabled entirely.
Existing APIRules `v1beta1` are no longer reconciled and their sub-resources are no longer owned or managed by the API Gateway module.
Already exposed workloads remain exposed and secured, but any change is no longer reconciled. 
Migrate your APIRules to version `v2`. See [#2666](https://github.com/kyma-project/api-gateway/issues/2666).
