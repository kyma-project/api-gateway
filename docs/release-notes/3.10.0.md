## Disabling APIRule `v1beta1` reconciliation

This release entirely disables reconciliation of APIRules `v1beta1`. 

The API Gateway module no longer reconciles APIRules `v1beta1` or any changes you make to these resources. It also no longer owns or manages APIRule subresources. However, workloads that are already exposed remain exposed and secured.

To maintain support for your APIRules, migrate them to version `v2`. For instructions, see [Migrate APIRule from Version `v1beta1` to Version `v2`](https://kyma-project.io/external-content/api-gateway/docs/user/apirule-migration/README.html). 

> [!WARNING]
> If you migrate before release 3.10, the migration does not cause downtime. If you migrate after this release, it may temporarily disrupt workload availability and access. For the APIRule deletion timeline for SAP BTP, Kyma runtime, follow [API Gateway What's New notes](https://help.sap.com/whats-new/cf0cb2cb149647329b5d02aa96303f56?locale=en-US&version=Cloud&q=api+gateway+module).
