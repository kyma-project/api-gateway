## Disabling APIRule `v1beta1` reconciliation

This release entirely disables reconciliation of APIRules `v1beta1`.
Existing APIRules `v1beta1` are no longer reconciled, and their sub-resources are no longer owned or managed by the API Gateway module. Already exposed workloads remain exposed and secured. However, changes made after this release won't be reconciled. 

Migrate your APIRules to version `v2`. To learn how to do this, see [Migrate APIRule from Version `v1beta1` to Version `v2`](https://kyma-project.io/external-content/api-gateway/docs/user/apirule-migration/README.html). For the APIRule deletion timeline for SAP BTP, Kyma runtime, follow [API Gateway What's New notes](https://help.sap.com/whats-new/cf0cb2cb149647329b5d02aa96303f56?locale=en-US&version=Cloud&q=api+gateway+module).

For more information, see [#2666](https://github.com/kyma-project/api-gateway/issues/2666).
